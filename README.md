# Present-Service – Website-Relaunch

Neue, eigenständige Vorschau der Present-Service-Website auf Basis der bestehenden Firmenwebsite. Die Live-Website bleibt unverändert.

Die Umsetzung enthält polnische B2B-Verkaufstexte, Angebotsbereiche, Anfrage-Konfigurator und responsives Design. Die Datenbank ist bewusst nicht angebunden. Alle Reichweiten-, Rechtstexte und Kontaktdaten sind vor einer Veröffentlichung auf der Firmendomain nochmals freizugeben.
